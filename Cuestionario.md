 # Conceptos que debes entender antes de programar

 
 **4.1 ¿Qué es una página web?**

 *Una página web es un documento que puede verse desde un navegador. Puede tener texto, imágenes, botones, formularios, videos, enlaces y muchas otras cosas.*

 - Explicar con mis propias palabras:


 > para mi una pagina web es un documento en el cual se puede obtener informacion de siertas cosas o buscar entretenimiento, normalmente no tienen mucha interision o en si es nula,tambien para entrar a una pagina web siempre se nesecitara un navegador.


 **4.2 ¿Qué es un navegador?**

*El navegador es el programa que usamos para ver páginas web.*

 - Explicar con mis propias palabras:

 >un navegador es lo que nos permite como su nombre lo indica navegar por la red y es nesesario para entrar a cualquier pagina o app web.


 **4.3 ¿Qué es HTML?**

 *HTML es el lenguaje que se usa para crear la estructura de una página web.*

 - Explicar con mis propias palabras:

 >HTML se podria decir que es el lenguaje que se encarga de asignar el titulo y el cuerpo principal de la pagina, su funcion no es en si los colores o la creatividad visual de la pagina pero si tiene aportacion visual en esta.


**4.4 ¿Qué es CSS?**

*CSS es el lenguaje que se usa para darle estilo a la página.*

 - Explicar con mis propias palabras:

>el css se usa para darle mas color y vida a una pagina,un ejemplo podria ser que con el html pudes escribir un titulo pero con el css podrias darle color y forma.

**4.5 ¿Qué es JavaScript?**

*JavaScript es el lenguaje que permite que una página tenga comportamiento.*

 - Explicar con mis propias palabras:

 >el lengaje de java es el que le da movimiento y vida a la pagina,logra hacer que las interacciones que tenga un usuario de una pagina tengan una respuesta y una funcion.
